# 魔法映画検定

- **役割**：CTO
- **目的**：映画『ハリー・ポッター』シリーズ全8作から出題する、ブラウザで遊べる4択クイズ
- **日付**：2026-09-30（チーム対抗モード追加：2026-10-08）

ファンが作った非公式クイズです。作品・難易度・問題数を選んで遊べます。

## 特徴

- 全117問（全8作＋シリーズ横断）、難易度は ★ 初級 / ★★ 中級 / ★★★ 上級（一部は原作小説の設定から出題）
- 出題順と選択肢の並びは毎回シャッフル
- 正解で金の火花、不正解で煙と揺れのエフェクト。背景に漂う光の粒と星
- 結果画面で称号と、間違えた問題の見直しリストを表示
- キーボード操作（1〜4 で回答、Enter で次へ）、スマホ対応、`prefers-reduced-motion` 対応
- タイトル画面のオープニング映像は Higgsfield（Seedance 2.5）で生成したオリジナル映像

## チーム対抗モード（テレビ・プロジェクター向け）

- 2〜4チーム。チーム名は自由に変更でき、得点は各チームの瓶に光がたまる得点ボードで表示
- 回答するチームは問題ごとに順番に回る（1問正解で1点）
- 回答形式は「4択（選択肢あり）」と「口頭回答（選択肢なし）」から選択
  - 4択：チームの答えた選択肢を司会者がクリック
  - 口頭回答：司会者が「○ 正解」「✕ 不正解」で判定（キーボードの O / X でも可）。答えは「司会者用」ボタンを押している間だけ表示
- 横取りルールはあり／なしを選択。不正解のとき、まだ答えていないチームが横取りで回答できる
- 最後に優勝チームの発表と順位表、誰も正解できなかった問題の一覧を表示

## ファイル構成

```
index.html          公開用ページ（build.js で生成。直接開いても動く）
assets/opening.mp4  オープニング映像
src/questions.js    問題データ（f:作品番号 lv:難易度 q:問題 o:選択肢 a:正解の添字 e:解説）
src/template.html   ページのテンプレート
build.js            index.html を生成するスクリプト
```

## 問題を追加・修正するとき

1. `src/questions.js` を編集する
2. `node build.js` を実行して `index.html` を作り直す

## 注意

- 作品の公式ロゴ・紋章・キャラクターの画像は使っていません。デザインと映像はオリジナルです。
- 『ハリー・ポッター』は J.K. Rowling および Warner Bros. の作品です。本クイズは公式とは無関係です。
